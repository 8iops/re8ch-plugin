# Re8ch

Start by discovering the active organization, available resource operations,
ready namespaces and grant entitlements. Use only the exact tools and schemas
returned by the current connection.

For material changes, inspect or plan first, then apply the smallest requested
change and verify the resulting state. Keep tenant, namespace, resource and
operation references together. Do not infer cross-tenant access from an
administrator catalog or from a user-supplied tenant name.
